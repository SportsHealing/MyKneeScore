# mykneescore.com: security status

Last updated: 2026-10-08. Living document. Update it with every security change.

Not published: `tools/` is excluded in `_config.yml`.

## Overall rating
- Before audit: **Medium**. No critical or high issues.
- After this branch is merged to `main`: **Low**.
- Why low: static site, no backend, no accounts, no database, no stored data,
  no secrets. Answers are scored in the browser and never sent anywhere.

## Architecture (as audited)
- GitHub Pages, built by Jekyll from `main`. Custom domain `mykneescore.com`.
- Pages: `index.html` (Short Knee Score), `anatomy.html`, `advanced/*.html`
  (generated by `tools/advanced/build.mjs`).
- JavaScript: one inline script each in `index.html` and `anatomy.html`;
  `advanced/assets/*.js`.
- Third parties before audit: Google Fonts only. After: none.
- CI: `.github/workflows/checks.yml`. No deploy step, no secrets.

### Evidence
- **F1**: `curl -I https://mykneescore.com/tools/advanced/STATUS.md` returned
  `200 text/markdown` on 2026-10-08. Files exposed internal decisions, the
  name of a private repo and a private preview link. No keys or passwords.
- **F2**: every page had `<link href="https://fonts.googleapis.com/css2?...">`.
  `llms.txt` says "nothing is sent anywhere". Under UK GDPR an IP address is
  personal data. Courts in the EU have found Google Fonts embedding unlawful
  without consent (LG Munchen, 3 O 17493/20, January 2022).
- **F3**: no CSP header or meta tag on any page. No XSS was found, so this is
  hardening. GitHub Pages cannot set custom headers, so a meta tag is used.
- **F4**: live response headers show none of these. GitHub Pages cannot add
  them. `frame-ancestors` is ignored in a meta tag. Risk is small: the site has
  no logins or actions to clickjack. HTTP already 301s to HTTPS.
- **F5**: `npm install -g playwright@latest`, `actions/checkout@v4`, no
  `permissions:` block.
- **F6**: not checkable from the repo. An unverified custom domain can be
  claimed by another GitHub user if Pages is ever switched off.
- **F7**: no privacy page linked from any page.
- **F8**: `git log` shows a personal Gmail on several commits.

## Changes made (branch `claude/sleepy-bohr-0pbo5y`)
- `_config.yml`: excludes `tools`, `CLAUDE.md`, `README.md` from the build. (F1)
- `fonts/`: self hosted Cormorant Garamond and Hanken Grotesk, latin and
  latin-ext subsets, with OFL licences. All pages and the build template link
  `fonts/fonts.css`. (F2)
- CSP meta on all pages: `default-src 'none'`, scripts from self plus a sha256
  hash per inline script, `connect-src 'none'`, `form-action 'none'`,
  `base-uri 'none'`, `object-src 'none'`. Same in `tools/advanced/build.mjs`. (F3)
- `<meta name="referrer" content="no-referrer">` on all pages. Hardening.
- CI: `permissions: contents: read`, actions pinned to commit SHAs,
  `persist-credentials: false`, Playwright pinned to 1.63.0. (F5)
- `tools/checks/house-style.py`: three new checks. CSP present and hashes
  match; no third party resources; `_config.yml` excludes internal files.
  Mutation tested: three deliberate breakages, three caught.
- `CLAUDE.md`: security rules for future AI edits.
